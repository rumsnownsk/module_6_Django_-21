# Simple Python HTTP Server

Учебный проект веб‑сервера на стандартной библиотеке Python (`http.server`). Реализует базовый роутинг, обработку форм, отдачу статики и защиту от LFI‑атак. Проект разрабатывается в рамках изучения Python 3.12, Poetry и тестирования (pytest).

## 🎯 Цели проекта

Этот проект создан для отработки следующих навыков:
*   **Работа с низкоуровневым HTTP:** понимание того, как работают заголовки, статусы и тело запроса без фреймворков (Django/FastAPI).
*   **Управление окружением:** использование Poetry для изоляции зависимостей.
*   **Безопасность:** реализация базовой защиты от Local File Inclusion (LFI) при отдаче статики.
*   **Паттерны веб‑разработки:** применение PRG (Post/Redirect/Get) для предотвращения повторной отправки форм.
*   **Документация:** формирование понятного README и docstring для поддержки кода.

## 🚀 Возможности

*   **Роутинг страниц:** поддержка ЧПУ (человекопонятных URL) для разделов сайта (`/`, `/catalog`, `/contact` и т.д.).
*   **Отдача шаблонов:** загрузка и рендеринг HTML из папки `templates`.
*   **Безопасная статика:** отдача CSS, JS, картинок из `public_html` с проверкой путей (защита от выхода за пределы директории).
*   **Обработка форм:** парсинг `application/x-www-form-urlencoded`, извлечение данных, логирование и редирект.
*   **Чистый вывод:** отключение стандартного шумного логирования сервера (`BaseHTTPRequestHandler`).

## ⚙️ Установка и запуск

### Требования
```bash
poetry install
poetry run python main.py
```
Сервер доступен по адресу: `http://localhost:8080`.


## ⚙️ Описание компонентов

### Класс `MyServer`

Наследуется от `BaseHTTPRequestHandler`. Обрабатывает HTTP-запросы (GET и POST).

| Метод | Описание |
| :--- | :--- |
| `log_message(format, *args)` | Отключает стандартное логирование запросов в консоль. |
| `_render_view(view_page)` | Формирует имя файла (`{view_page}.html`) и вызывает `read_template`. |
| `do_GET()` | Обрабатывает GET-запросы: отдаёт статику, роутит по `route_map`, рендерит шаблоны, возвращает 404 при отсутствии страницы. |
| `do_POST()` | Обрабатывает POST-запросы: парсит данные формы, выводит в консоль, делает редирект 303 на `/contact` (паттерн PRG). |


### ⚙️ Функции

#### `read_template(filename: str) -> str`

Читает HTML-шаблон из папки `templates/`.

- Успех — возвращает содержимое файла как строку.
- Файл не найден — возвращает заглушку `<h1>Файл не найден</h1>` (сервер не падает).

#### `serve_static_file(path: str) -> tuple`

Отдаёт статические файлы (CSS, JS, картинки) из папки `public_html/`.

- Проверяет путь через `os.path.commonpath` — защита от LFI (нельзя запросить `../../etc/passwd`).
- Возвращает кортеж `(content_bytes, mime_type)` при успехе.
- Возвращает `(None, 403)` при попытке выхода за пределы директории.
- Возвращает `(None, 404)` если файл не найден.
